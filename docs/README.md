# PackFlow 문서

작성일: 2026-11-20 · 상태: 골격(Wave 0) 전, 코드 없음

PackFlow는 소규모 판매자(구매대행 · 부업 포함)가 엑셀과 메모로 따로 관리하던 **구매 → 입고 → 재고 → 출고** 흐름을 한 화면에서 다루는 미니 ERP다. 바이브 코딩 해커톤(2026-11-19 ~ 11-26) 결과물이다.

- 원본 계획서: [pack-flow-plan.md](pack-flow-plan.md). 범위 · Step · 완료 판정 테스트는 계획서가 기준이다.
- 이 폴더의 00~08은 계획서를 **엔터프라이즈 아키텍처 관점**으로 다시 나누고, 네 명이 **충돌 없이 동시에** 만들 수 있게 경계를 그은 문서다.
- 제출용 `DevelopDoc/`(PRD · TECH_SPEC · WORK_UNITS · FINAL_CHECKLIST)은 4일차(11/25)에 이 문서들을 요약해 만든다(D-12).

## 표기

- **D-번호 · P-번호**: 모두 확정한 결정. P는 Claude 제안에서 출발해 2026-11-20 eple이 승인한 것으로, 참조 유지를 위해 번호를 그대로 둔다.
- **WU-번호**: 작업 단위. 브랜치 이름 `feat/WU-번호-주제`, PR 제목, 커밋 메시지에 같은 번호를 쓴다.
- **Step 1~5**: 계획서 3절의 MVP 단계. **Wave 0~3**: 날짜로 나눈 작업 묶음([06](06-work-plan.md)).
