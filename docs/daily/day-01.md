- Step 3 (필수) AI 에이전트: 품절 임박 발주서 초안 + 자연어 재고 조회 · 출고 (확인 후 실행)
- Step 4 (도전) 자금회수: 정산대기 / 입금완료 금액 집계
- Step 5 (도전) 사진 OCR 등록, 구글 로그인
- 하지 않을 기능: 회계 · 세무, 다중 창고, 실시간 택배 API, 결제, 창고 모니터링(YOLO), 세밀한 권한 관리

## AI 활용

**1일차에 확인할 것**

**무료 크레딧 · 요금제 · 요청 한도 :** 

- 개발 중: 로컬 Ollama 사용 → 무료, 요청 한도 없음 (내 PC 성능이 한도)

- 발표용: Gemini API 무료 티어 (결제 계정 연결 안 함, 카드 등록 불필요)
· AI Studio: https://aistudio.google.com/
· 기본 모델 Flash-Lite: 분당 15회 / 하루 500회 (2026년 10월 공개 자료 기준)
· 한도는 프로젝트 단위, 하루 한도는 한국 시간 오후 4~5시에 초기화
- 유료 전환은 팀 합의 후에만

**팀원 각자 계정으로 쓸 수 있는지 (계정 공유 금지) :** 

- Ollama: 계정 필요 없음. 각자 PC에 설치해 사용
· 팀 공통 모델 1개로 통일: ______ (예: qwen3.5:4b, 사양이 낮으면 3B급)
· 확인 결과: eple ■ / sorek-charlie ☐ / skygaul ☐ / jkspawn ☐ 설치 · 실행 완료
- Gemini: 발표용 키 1개만 발급 (발급자: ___), 본인 계정으로만 관리하고 공유하지 않음
· 키는 Render 환경변수(GEMINI_API_KEY)에만 등록, GitHub에 올리지 않음
· 확인 결과: eple ■ / sorek-charlie ☐ / skygaul ☐ / jkspawn ☐ 설치 · 실행 완료

**배포 환경과 맞는지, 결과물을 가져갈 수 있는지 :** 

- 개발할 때: 각자 PC에 설치한 Ollama로 AI 기능을 테스트
- 배포했을 때: Render에 올린 서비스는 Gemini를 사용 (Render 서버는 우리 PC의 Ollama에 연결할 수 없음)
- 바꾸는 방법: AI를 부르는 코드를 파일 하나(lib/llm.ts)에 모아 두고, 설정값 하나만 바꾸면 Ollama ↔ Gemini 전환
- 주의: 두 AI는 답변 스타일이 다를 수 있음 → 4일차 리허설 때 Gemini로 시연 순서를 한 번 미리 돌려 보기
- 결과물: 코드는 팀 GitHub에 남으니 수업이 끝나도 계속 쓸 수 있음
- 데이터: Ollama는 내 PC 안에서만 동작해 데이터가 밖으로 나가지 않음 / Gemini 무료 버전은 입력한 내용이 구글 서비스 개선에 쓰일 수 있으니 가짜 데이터만 사용
- 라이선스: Ollama 모델마다 사용 조건이 다르니, 고른 모델의 조건을 한 번 확인
