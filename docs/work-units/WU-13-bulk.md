## 고치는 방법

1. `parse(text, format)` → `{ rows: BulkRowInput[], errors: {line, reason}[] }`
   - 줄바꿈 `\r\n` · `\n` 모두, TSV는 `\t`, CSV는 쉼표 + 큰따옴표 감싼 값
   - 첫 줄이 `구분, 품목코드, 수량, 거래처, 송장번호, 비고` 머리글이면 건너뜀
   - 열 개수 6이 아니면 `열 개수 오류`, 구분이 입고/출고가 아니면 `구분 값 오류`, 수량이 1 이상 정수가 아니면 `수량이 0 이하`
   - 같은 붙여넣기 안 송장번호 중복 → 두 번째부터 `같은 붙여넣기 안 송장번호 중복`
   - `=`, `+`, `-`, `@`로 시작하는 셀은 글자로만(계산하지 않음)
   - 500행 · 100KB 넘으면 전체 거절
2. 화면: 붙여넣기 칸 또는 CSV 파일 선택 → [미리보기] → 서버 미리보기 결과 표(유효 행 초록, 오류 행 빨강 + 사유) → [유효한 N행 반영] → 결과 "7행 반영, 3행 제외(사유)"
3. 빈 붙여넣기: "행이 없어요", 반영 버튼 비활성
4. 시연용 [예시 붙여넣기] 버튼(오류 3행 섞인 10행 샘플)
5. testid: `bulk-textarea`, `bulk-csv-input`, `btn-bulk-preview`, `bulk-row-<line>`, `bulk-row-error-<line>`, `btn-bulk-commit`, `bulk-result`

## 입력 · 오류 처리 ([04](../04-api-contract.md) 4절)

- 행 검사는 `src/lib/validation/`의 `bulkRow` 스키마를 그대로 쓴다(수량 1~100,000, 송장번호 형식 · 50자, 메모 200자 — [04](../04-api-contract.md) 4.2). `parse.ts`는 줄 · 열 나누기와 머리글 · 수식 셀 처리만 하고, 값 판정은 스키마에 맡긴다
- 오류 사유 문구는 04 4.3 · 4.4와 같게(새 문구를 짓지 않는다)
- 빈 송장 · 빈 메모 칸은 `null`로

- 한 것:
- `src/lib/bulk/parse.ts` — `parse(text, format)` 순수 함수(DB 없음). 서버 미리보기 라우트(WU-43)가 쓴다
  - TSV(엑셀 · 시트 붙여넣기) · CSV: 큰따옴표 감싼 칸(쉼표 · 줄바꿈 · `""`), `\r\n` · `\n` 모두
  - 첫 줄이 `구분, 품목코드, 수량, 거래처, 송장번호, 비고` 머리글이면 건너뜀, 빈 줄 건너뜀, 줄 번호는 원본 기준
  - 행 판정: 열 개수 6 아님 → `열 개수 오류`, 구분이 입고/출고 아님 → `구분 값 오류`, 수량이 1 이상 정수 아님 → `수량이 0 이하`(04 3.6). 그 밖의 칸 규칙(품목코드 형식 · 거래처 길이 · 송장 형식 · 메모 200자 · 수량 상한)은 `bulkRow` 스키마가 판정하고 04 4.3 문구를 씀
