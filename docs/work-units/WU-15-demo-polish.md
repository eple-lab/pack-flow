1. [시연 데이터 초기화] → 확인 창 → `POST /api/seed {dataset:"demo"}` → 대시보드 새로고침 (testid `btn-seed-reset`)
2. 시연 순서대로 직접 돌려 보고 막히는 곳 수정: 로그인 → 입고 → 출고 → 품절 임박 카드 → 발주서 초안 확인 → 출고 취소 · 재고 초과 거부 → B 계정 권한 거부
3. 휴대폰 폭에서 한 번 확인
4. 백업 영상 2분: 배포 URL에서 위 순서, 화면 녹화(소리 없이 자막 또는 짧은 나레이션)
