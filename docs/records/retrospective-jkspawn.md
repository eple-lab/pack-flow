## 1. 시작할 때 기대한 것
- 정정 흐름(부족 발견 → 발주 → 입고 → 출고 차단 → 정정)을 화면으로 끝까지 만들어 보기 (1일차 팀 목표 합의서에서 맡은 줄)
- AI 코딩 도구로 팀 프로젝트를 끝까지 해 보기 — WU 하나 = 브랜치 하나 = PR 하나

## 2. 처음 생각과 달라진 점

## 3. 느낀 점
AI가 쓴 코드도 그냥 믿으면 안 된다. 기대값을 먼저 적고 시험을 돌리니 문제가 바로 드러났다.
확인한 것과 확인 못 한 것을 나눠 말하는 게 중요하다. 발표에서도 확인 못 한 내용은 뺐다.
