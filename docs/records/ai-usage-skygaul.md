**AI가 틀린 것을 잡은 순간** (1~2개)
- 영상 처음 평가에서 AI가 숫자와 길이만 보고 "문제 없음"이라고 했을 때, "마우스가 어디를 클릭하는지 안 보임…"으로 짚음 → AI가 입력 장면을 약 1초로 재 보고 재촬영 요청문을 쓰고, 수정본을 같은 방식으로 다시 확인한 뒤 체크 (WU-15, PR #74)
- PR #47 리뷰에서 AI가 "시험을 다시 돌리지 않았다"고만 쓴 것을 "이건 왜 확인 못했지"로 되물음 → 두 시험을 실제로 돌려 확인하고 "확인 안 한 것"으로 명시하게 함

**다음 단계** (2~3개)
- 맡길 때 "다 됐다"의 기준을 한 줄 먼저 말하기 — 영상 확인은 포인터 · 자막 · 길이 · WU 완료 기준을 처음에 정해 두었다면 재촬영 한 번을 줄일 수 있었다.
- 모호한 한 문장은 의도를 같이 쓰기 — "시연영상 로컬로 돌린거로 대체 가능한가?"는 내 PC에서 앱을 띄워 찍은 영상인지, 자동 녹화한 영상인지 두 해석으로 갈렸고, AI가 둘 다 설명한 뒤에야 방향이 정해졌다.
- AI가 먼저 만든 산출물은 쓸 곳을 정하고 시키기 — 캡처 두 장을 뽑은 뒤 "이거 슬라이드에 쓰려고 하는거야?"로 의도를 확인했다.
